## Pinshot v0.2.0

带来离线贴图划词（OCR）、IDE/浏览器富文本代码贴图与动态卡片尺寸，以及多项并发与体验优化。

### 更新内容

- **贴图默认离线划词（OCR）**：
  - 内置纯 Rust 离线 PP-OCRv5 Mobile（ONNX）推理，无 C++ `libonnxruntime` 外部依赖；贴图创建后自动后台识别中英文与代码文字，100% 本地离线运行。
  - 鼠标悬停文字即切工字光标，左键拖动自由选字、双击选词，点击浮动「复制」或 `Ctrl+C` 即可复制；保留边缘拖拽热区与 `Alt` 拖拽，首选项与右键菜单均可随时开关。
  - Release 压缩包与 AUR 软件包均已内置 `ppocrv5-mobile` 模型，开箱即用；从源码构建时也支持右键一键下载或 `pinshot ocr download-models`。
- **富文本 / 代码高亮贴图与动态宽度**：
  - 剪贴板文本贴图并行只读解析 `text/html` 与 `text/plain`，完整保留 IntelliJ IDEA、VS Code、浏览器复制的语法配色、主题底色与粗斜体样式（含 Java/IDEA Unicode 变体识别与中英混排等宽对齐）。
  - 卡片宽度按内容自适应，短文本不再撑满固定宽度；超长行自动折行并裁掉右侧多余留白，超长单行文本亦可正常折行渲染。
- **右键菜单精简**：合并「复制原始文本」与「复制全部文字 (OCR)」为统一的 **「复制纯文本」**（文字卡片默认复制原始文本，图片贴图默认复制 OCR 文本）。
- **并发与隐私一致性加固**：缓存索引引入跨进程文件锁，防止并发关闭贴图丢状态；后台 OCR 写回前在锁内校验记录存在性与图片修订号，防止清理历史或标注替换后旧 OCR 文本残留。
- **AUR 自动发布**：Release 流水线支持在打 `v*` 标签后自动同步发布 `pinshot` 与 `pinshot-bin` 到 AUR。

### 安装

```bash
curl -fsSL https://raw.githubusercontent.com/dgxz99/pinshot/main/scripts/install.sh | bash
```

## English

Brings offline on-pin OCR text selection, rich-text/code clipboard cards with dynamic sizing, and concurrency & reliability improvements.

### What's Changed

- **Offline on-pin OCR text selection:**
  - Built-in pure-Rust PP-OCRv5 Mobile (ONNX) inference with zero external C++ runtime dependencies. Runs automatically in the background for every pin, 100% offline, supporting Chinese, English, and code.
  - Hover over text on any pin for an I-beam cursor, drag to select or double-click a word, and copy via the floating Copy pill or `Ctrl+C`. Edge drag grip and `Alt`-drag remain available; toggle globally in Preferences or per-pin via the context menu.
  - Prebuilt release archives and AUR packages bundle the `ppocrv5-mobile` models out of the box.
- **Rich-text / syntax-highlighted code cards & dynamic width:**
  - Reads `text/html` alongside `text/plain` (read-only) to preserve syntax colors, theme backgrounds, and bold/italic styling copied from IntelliJ IDEA, VS Code, and browsers, with aligned CJK/monospace font fallback.
  - Cards auto-size snugly to content width, wrap long lines cleanly without excess right whitespace, and safely handle very long single-line clipboard strings.
- **Cleaner pin context menu:** Unified "Copy original text" and "Copy all text (OCR)" into a single **复制纯文本** action (copies original text for text cards, OCR text for image pins).
- **Concurrency & privacy hardening:** Added cross-process file locking for `index.json` mutations and guarded OCR cache writes against cleared history or replaced images.
- **Automated AUR publishing:** Release workflow now publishes `pinshot` and `pinshot-bin` updates automatically on `v*` tags.

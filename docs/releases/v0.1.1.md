## Pinshot v0.1.1

面向 GNOME Shell 50 / 51（Wayland）的兼容性与安装体验更新。

### 更新内容

- **支持 GNOME Shell 50**：扩展 `metadata.json` 正式声明兼容 GNOME Shell 50 / 51（已在 Ubuntu 26.04 GNOME 50 与 Arch Linux GNOME 51 验证），D-Bus `Ping` 动态上报当前前端版本（`gnome-shell-50` / `gnome-shell-51`）。
- **一键安装体验优化**：
  - 自动检测并静默安装缺失的必需运行依赖（兼容 `sudo` / `doas`，失败时展示错误信息），安装完成后自动将扩展设为登录后自启。
  - 可选组件 `satty` 改为交互式确认安装；在系统仓库未收录 `satty` 的发行版（如 Ubuntu）上，支持自动从官方 Release 下载安装到 `~/.local/bin/satty`。
  - 环境变量传参更简洁：使用 `PINSHOT_VERSION=v0.1.1` 指定版本，不再需要 `bash -s --`。
- **支持远程完全卸载**：提供 `uninstall.sh` 远程卸载与 `PINSHOT_PURGE=1` 完全清理（含配置、缓存与 GSettings 设置，保留已导出的截图与 GIF）。

### 安装

```bash
curl -fsSL https://raw.githubusercontent.com/dgxz99/pinshot/main/scripts/install.sh | bash
```

## English

Compatibility and installation experience update for GNOME Shell 50 / 51 on Wayland.

### What's Changed

- **GNOME Shell 50 support:** `metadata.json` now officially supports GNOME Shell 50 and 51 (verified on Ubuntu 26.04 with GNOME 50 and Arch Linux with GNOME 51), and D-Bus `Ping` dynamically reports the running shell major version (`gnome-shell-50` / `gnome-shell-51`).
- **Improved installer:**
  - Automatically and quietly installs missing required runtime dependencies (supports both `sudo` and `doas`, showing error output on failure) and pre-enables the GNOME extension for next login.
  - Prompts interactively to install optional `satty`; on distros where `satty` is not in official repos (such as Ubuntu), falls back to downloading the upstream prebuilt binary into `~/.local/bin/satty`.
  - Cleaner piped options via environment variables (`PINSHOT_VERSION=v0.1.1`).
- **Remote full uninstall:** Added remote `uninstall.sh` support with `PINSHOT_PURGE=1` to also remove config, cache, and GSettings (while keeping exported screenshots and GIFs).
